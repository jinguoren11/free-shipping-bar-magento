# 实机测试需求 · 请总管（窗口 A）通过 ops-board 派单

目标：在真实 Magento 里装起来，验证三处显示、三种语言、各种购物车状态，并拍截图。

**ASUS（装到预览站）**
1. Magento Open Source 2.4.7 和 2.4.8（PHP 8.2/8.3），装好示例数据（需要简单商品 + 可配置商品）。
2. 把本仓库 `dist/getdropflow-module-free-shipping-bar-1.0.0.zip`（`./build/package.sh` 生成，分支 `claude/magento-free-shipping-bar-mqm0n2`）解压到 `app/code/GetDropFlow/FreeShippingBar`，执行：
   `bin/magento module:enable GetDropFlow_FreeShippingBar && bin/magento setup:upgrade && bin/magento deploy:mode:set production`（这一步同时验证"production 编译无错"），再 `cache:flush`。
3. 后台：启用 Free Shipping 方式，最低订单金额设 50；建 3 个商店视图：English(美元)、Español(欧元)、中文(人民币)；各装对应语言包。
4. 开启 Varnish（或至少开整页缓存）。

**Mac（拍截图，每种语言各一套）**
按 `docs/02-项目计划.md` 第 4 节的 13 种状态，在 小购物车 / 购物车页 / 商品页 三处各拍一张；重点：空车、差一点、刚好达标、超过、虚拟商品、用优惠券、换币种。
错误或显示异常的，截图红框标出，文件名写明 语言_位置_状态。

**回传**：截图 + 控制台报错（浏览器 F12）+ `var/log` 里新增的报错。
