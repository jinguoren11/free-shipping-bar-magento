# 免运费进度条 · 客户教程（中文）

> 适用：Magento 2.4.x（开源版 / Adobe Commerce），PHP 8.1 及以上。
> 说明：带 📷 的地方需要配截图，红框标注的位置见文末"截图清单"。

## 一、它能做什么
在 **小购物车、购物车页、商品页** 显示"再买 $12.50 就免运费！"和一条进度条，凑够后显示"恭喜！您已享受免运费"。三处可以单独关闭。
- 📷 图1：三处效果总览

特点：
- 自动读取 Magento 自带"免运费"方式里的最低订单金额，不用重复填；也可以自己填一个金额。
- 顾客加购、删除、改数量、用优惠券后**马上更新**，不用刷新页面。
- 不影响整页缓存 / Varnish。
- 自动用顾客当前的币种和商店视图的语言（自带英文、西班牙文、中文，其他语言显示英文），也可以为每个商店视图自己写文案。
- 购物车里只有虚拟商品（不用发货）时自动隐藏。
- **只读**：只读购物车金额，不改订单、价格、支付、运费，不联网，不存顾客数据。

## 二、安装
在 Magento 根目录执行（生产模式全部要执行）：
```
composer require getdropflow/module-free-shipping-bar
bin/magento module:enable GetDropFlow_FreeShippingBar
bin/magento setup:upgrade
bin/magento setup:di:compile
bin/magento setup:static-content:deploy -f
bin/magento cache:flush
```
卸载：`bin/magento module:disable GetDropFlow_FreeShippingBar` → `composer remove getdropflow/module-free-shipping-bar` → `bin/magento setup:upgrade` → `bin/magento cache:flush`。插件不建数据库表。

## 二（补）、更新版本
- **Marketplace 版**：通过 Adobe 的更新机制（Composer）：`composer update getdropflow/module-free-shipping-bar`，再执行 `setup:upgrade`、`setup:di:compile`、`setup:static-content:deploy -f`、`cache:flush`。插件**不会自己下载或替换代码，也不联网**；设置会保留。
- **官网/GitHub 下载版**：设置页有"升级卡片"：点"检查更新"→一键升级，自动备份，出错自动退回（该功能正在完成中，发布前请按"重新手动安装新版 zip"升级）。

## 二（补2）、主题兼容
适用 Magento 标准主题（Luma、Blank）及基于它们的主题；样式类名都以 `gdf-fsb-` 开头，文字颜色和字体继承主题，窄屏可用。位置不对或不显示时，用 **Theme Compatibility（主题兼容）** 设"自定义位置"。**Hyvä 主题必须同时安装**兼容包 `getdropflow/module-free-shipping-bar-hyva`：不装的话 Hyvä 店铺上没有进度条（也不会报错）。Hyvä 上进度条显示在购物车页、商品页（加入购物车行下方）和购物车抽屉（商品列表上方）。详见 `docs/THEMES.md`。

## 三、两分钟上手
1. 后台进入 **商店 → 配置 → 销售 → 交付方式 → Free Shipping**：**Enabled** 选 Yes，**Minimum Order Amount** 填大于 0 的数（例如 50），保存。 📷 图2
2. 进入 **商店 → 配置 → 销售 → 免运费进度条（Free Shipping Progress Bar）**，确认 **Enable** 是 Yes，保存。 📷 图3
3. **系统 → 缓存管理** 清缓存。
4. 到前台加一个商品进购物车，三处就会出现进度条。

## 四、设置说明
路径：**商店 → 配置 → 销售 → Free Shipping Progress Bar**。大部分设置可以按网站、商店视图分别设（左上角切换范围）。

**General（总体）**：Enable 总开关；Show in Mini Cart / Cart Page / Product Page 三处各自开关。
**Free Shipping Threshold（门槛）**：
- Threshold Source = *Magento Free Shipping method (automatic)*：自动读取免运费方式的最低订单金额；=*Custom amount*：用下面自己填的金额。
- Custom Threshold：用**基础货币**填，顾客看到的是换算成他们币种的金额。
- 自动模式下，免运费方式没启用或金额为空/0 时，进度条不显示。
**Messages（文案）**：留空用自带文案（自动翻译成当前语言）；想自己写就填，可用 `{{amount}}`（还差多少）和 `{{threshold}}`（门槛）。可以按商店视图分别写。 📷 图4
**Appearance（外观）**：进度条颜色（如 `#3b6ea5`，写错会自动用默认色）；是否显示进度条；是否显示百分比。
**Theme Compatibility（主题兼容）**：购物车页/商品页/小购物车各一个"自定义位置（CSS 选择器）"，填页面上某个元素的选择器（如 `.page-title-wrapper`、`#maincontent`），再选"相对位置"（之前/之后/内部开头/内部末尾）。留空=标准位置；页面上找不到该元素时进度条不显示（不会报错）。
**About（关于）**：Show "More tools" Panel——设置页底部作者其他工具的静态小列表，**不联网、不收集数据**。**Marketplace 版默认关，下载版默认开**。

## 五、金额怎么算
- 用**优惠后的购物车小计**和门槛比较（和 Magento 免运费方式同口径）；刚好等于门槛算达标；运费不算在内。
- 用优惠券后降到门槛以下，会变回"再买 X"。
- 进度条只是**提示**，最终有没有免运费由结账时的 Magento 决定。
- **插件不读取**：免运费方式里的"限定国家"、客户组、购物车价格规则/商品上的免运费。如果你的免运费取决于这些，进度条可能与结账不一致——请关掉进度条，或填一个符合你规则的自定义金额。

## 六、顾客看到的状态
| 购物车 | 显示 |
|---|---|
| 空 | 购物车页、商品页显示"订单满 $50.00 免运费"（无进度条）；小购物车不额外显示（只有主题自带的"购物车为空"） |
| 没到门槛 | "再买 $12.50 即可免运费！"+ 进度条 |
| 达标 | "恭喜！您已享受免运费。"+ 满条 |
| 只有虚拟商品 / 插件关闭 / 免运费方式关闭 | 不显示 |
📷 图5：三种状态

**改设置后多久生效**：后台改了文案、颜色或开关，已经打开页面的访客要等他们的购物车数据重新加载才会看到——通常是他们下一次操作购物车，或 Magento 的顾客数据过期（默认 60 分钟）。之后新打开的页面用新设置。清缓存不会改变已经存在访客浏览器里的数据。

## 七、出问题怎么办（报错说明）
| 现象 | 原因与处理 |
|---|---|
| 哪里都不显示（Hyvä 主题） | 安装 Hyvä 兼容包 `getdropflow/module-free-shipping-bar-hyva`，`bin/magento module:enable GetDropFlow_FreeShippingBarHyva`，`setup:upgrade`，清缓存。 |
| 哪里都不显示 | ①当前商店视图的 Enable 是 Yes？②自动模式下：Free Shipping 方式已启用、最低订单金额>0（且是对应网站）？③清缓存；生产模式还要重新部署静态文件 `setup:static-content:deploy -f`；④购物车是否只有虚拟商品。 |
| 购物车页有、小购物车没有 | 主题要用 Magento 标准小购物车。主题自己换了小购物车的，用"小购物车：自定义位置"。 |
| 购物车页有、商品页没有 | 检查 Show on Product Page；自定义商品页布局要保留标准的 `product.info.main` 区块。 |
| 文字语言不对 | 文案跟随商店视图语言。设置里留空=自带翻译；在某个商店视图里自己写的文案只在那个商店视图显示。切换商店视图后刷新一次页面。 |
| 金额币种不对 | 自定义门槛是按**基础货币**填的，再换算。检查 **商店 → 货币汇率**。 |
| 改了购物车金额不更新 | 清浏览器缓存；按 F12 看控制台有没有包含 `free-shipping-bar` 或 `bar.js` 的报错（可能被别的插件或主题改动挡住了）。 |
| 进度条说免运费，结账却没有 | 见"五、金额怎么算"里"插件不读取"的部分。 |
| 设置页底部没有"更多工具" | 被 Show "More tools" Panel 关掉了，或你在网站/商店视图范围查看（只在"默认配置"范围显示）。 |

反馈问题时请附上：Magento 版本、PHP 版本、主题名、浏览器控制台（F12）报错、`var/log/system.log` 里的相关行。
