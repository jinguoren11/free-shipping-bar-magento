# 项目计划：Free Shipping Progress Bar（Magento 2 免费插件）

## 1. 功能清单

**前台（买家看到）**
- 小购物车（迷你购物车）、购物车页、商品页 三处显示："再买 $X 就免运费" + 进度条；达标后显示"已享受免运费"。
- 购物车为空时显示"满 $X 免运费"。
- 金额按买家当前币种显示；文字按当前商店视图语言显示。
- 加/减/改数量、删商品后**不刷新整页**自动更新。
- 不破坏 Varnish/整页缓存（数据由前端实时读取，不写进缓存页）。
- 全虚拟商品购物车（不需要运费）不显示。

**后台（商家设置）** 路径：商店 → 配置 → 销售 → 免运费进度条
- 总开关；三个位置各自开关。
- 门槛来源：① 自动读取 Magento 的 Free Shipping 方式最低订单金额（默认）② 手动填写覆盖。
- 文案：未达标/已达标/空购物车 三段，可按商店视图分别覆盖；留空则用内置多语言文字。
- 外观：进度条颜色、是否显示进度条/百分比（不写任何行业默认值，颜色默认中性）。
- 作者信息一行（getdropflow.com，无购买诱导）。

**明确不做**：不碰订单、支付、运费计算本身；不改购物车价格；不收集任何数据；不联网。

## 2. 技术方案要点

- 门槛：`carriers/freeshipping/free_shipping_subtotal`（Free Shipping 方式未启用且没填覆盖值 → 条不显示）。
- 已购金额：报价单 `base_subtotal_with_discount`（和 Magento 免运费判断同口径，含优惠后），换算成显示币种。
- 前端：自定义 customer-data 区块 `free-shipping-bar`，加购/改数量/删除/优惠券后自动失效重载。
- 一个 Knockout 组件，三处复用。
- 计算逻辑拆成**不依赖 Magento 的纯类**，可以直接单元测试。

## 4. 测试清单

**语言**：英文(en_US)、西班牙文(es_ES)、简体中文(zh_Hans_CN) 三套都要测；另测"无翻译语言回退到英文"。
**购物车状态（每种语言都过一遍，三个位置都看）**：
1. 空购物车  2. 未达标（差很多/差一点）  3. 刚好等于门槛  4. 超过门槛
5. 只有虚拟商品  6. 用优惠券后降到门槛以下  7. 改数量/删商品实时变化
8. 切换币种（门槛和差额要按汇率换算）  9. 多商店视图不同语言/不同覆盖值
10. Free Shipping 方式关闭 + 无覆盖值（不显示）  11. 后台关闭总开关/单个位置
12. 未登录/已登录  13. Varnish 开启下缓存页面照常、条仍实时更新
**Magento 官方 QA 回归**：游客下单、多地址结账、再次下单、心愿单、比较、后台开发票（审核会跑）。
**环境**：Magento 2.4.7 / 2.4.8，PHP 8.2 / 8.3，production 模式编译，`composer require` 安装。
**自动化**：PHPUnit 单元测试（计算、文案）；phpcs Magento2 标准；`php -l`；禁止 TODO/FIXME 扫描。
